# iOS Rock Paper Scissors

A fun and animated Rock Paper Scissors game built with SwiftUI for iOS devices. Challenge the computer in this classic game with smooth animations and a kid-friendly interface!

##  Game Features

- **Classic RPS Gameplay**: Choose between Rock, Paper, or Scissors
- **Smart Computer AI**: Computer makes random choices for fair gameplay
- **Bounce Animation**: Iconic 3-bounce effect mimicking real-world RPS games
- **Universal Compatibility**: Designed to work on all iOS devices without crashes
- **SF Symbols Icons**: Clean, consistent iconography using Apple's SF Symbols
- **Instant Results**: Clear win/loss/tie feedback after each round

##  User Interface

- **Large, Touch-Friendly Buttons**: Easy to tap game choice buttons
- **Animated Computer Display**: Computer's choice bounces 3 times before revealing
- **Clear Result Messages**: "You Win!", "Computer Wins!", or "It's a tie!"
- **Modern SwiftUI Design**: Clean, native iOS appearance
- **Responsive Layout**: Adapts to different screen sizes

##  Technology Stack

- **SwiftUI**: Modern declarative UI framework
- **SF Symbols**: Apple's comprehensive icon library
- **iOS 14+**: Compatible with modern iOS versions
- **Swift**: 100% Swift implementation
- **Native Animations**: Smooth ScaleEffect animations

##  Target Audience

- **Children & Kids**: Simple, intuitive gameplay perfect for young users
- **Casual Gamers**: Quick entertainment for all ages
- **iOS Developers**: Clean example of SwiftUI game implementation
- **Learning Projects**: Great reference for SwiftUI animations and state management

##  How to Play

1. **Launch the App**: Open the app to see the game interface
2. **Choose Your Move**: Tap Rock (circle), Paper (raised hand), or Scissors
3. **Watch Animation**: Computer's choice bounces 3 times while "thinking"
4. **See Results**: Game announces winner based on classic RPS rules
5. **Play Again**: Tap another choice to play another round instantly

##  Game Rules

- **Rock** (circle) beats **Scissors** ✅
- **Paper** (raised hand) beats **Rock** ✅  
- **Scissors** beats **Paper** ✅
- **Same choice** = **Tie** 


##  Installation & Setup

### Prerequisites
- **Xcode 12.0+** (for SwiftUI support)
- **iOS 14.0+** deployment target
- **Swift 5.3+**

### Running the App
1. Clone or download the project
2. Open `RPS.xcodeproj` in Xcode
3. Select your target device or simulator
4. Press `Cmd+R` or click the ▶️ play button
5. The app will build and launch automatically

### Device Compatibility
- **iPhone**: All models supporting iOS 14+
- **iPad**: Full compatibility with larger screen support
- **iPod Touch**: Supported on newer models
